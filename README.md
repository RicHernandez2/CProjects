# CProjects

This is the root for Claude Projects as they get built — each project lives in its own top-level folder here.

## Structure

Each project is a self-contained folder at the repo root:

```
CProjects/
├── project-one/
├── project-two/
└── ...
```

A project folder should be runnable on its own (its own README, dependencies, etc.) — this repo just collects them under one roof.

## Adding a project

1. Create a new top-level folder named for the project.
2. Give it its own `README.md` describing what it does and how to run it.
3. Keep its dependencies/config self-contained within the folder.
